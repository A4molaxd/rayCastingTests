A very basic test to try coding a ray tracer. 

It features 2D with views of the rays and 3D with the perspective of the ray's font. You can toggle between this views with "Space".

- Move: W A S D.
- Look around: Arrow keys.

Added raymarching too, this time with real 3D.

- Move: W A S D Space Shift.
- Look arround: Arrow keys.

Learned the fundamentals from Iñigo Quilez website: iquilezles.org, and Youtube channel: youtube.com/c/InigoQuilez. Go check that out, he explains this topic in a very undestandable way.
